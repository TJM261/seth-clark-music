# seth-clark-music

- `.htaccess` — 301 redirect from `sethclarkmusic.com` to `sethpeterclarkmusic.com`.
- `visualizer/` — [Visualizer Studio](visualizer/README.md), a desktop music
  visualizer that records reactive video for a track. Open
  `visualizer/index.html` in Chrome or Edge to use it. It runs locally and is
  not part of any website.
